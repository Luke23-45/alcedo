## What changed vs. the reference — and why

| Reference | Redesign | Reason |
|---|---|---|
| Toggle "Save as new workout" + sub "Push Day will be updated" (self-contradictory) | **Segmented control** `Update Push Day / Save as New` + a one-line consequence | A toggle whose caption argues with its own state is the single worst element on the screen. Two explicit modes remove the ambiguity entirely. |
| "6 selected" while only 5 rows are checked and 1 is locked | **"5 SELECTED"** chip, computed from actual checked rows | Law III. The locked *Session name* row is not selectable, so it is not counted; it carries an `ALWAYS` tag and a lock glyph instead of an empty checkbox (an empty box wrongly implied "off"). |
| Flat grey cards, no grouping logic | Tinted card borders + coloured group headers: green `ADDED`, red `REMOVED`, amber `MODIFIED`, neutral `SESSION`, each with a right-aligned count | The diff type is legible before you read a word. |
| "4 → 5" as plain grey sub-text | **Transition typography**: old value `#6C6C70` → arrow `#48484A` → new value white 600, plus a delta chip (`+1`, `+30 s`) | A diff should *show* the delta, not bury it. |
| Full-width Save only | Sticky bar with **Discard** (destructive ghost) + **Save 5 Changes** (brand, count in label) | The button label states exactly what will happen; a destructive escape hatch sits beside it, not buried in a menu. |
| No scroll/edge treatment | Material-backed sticky bar with hairline; content ends clear of it | Consistent with every other Kinetic sticky surface. |
| Orange back chevron floating on black | Brand-tint chevron in a proper nav bar with `Reset` action | `Reset` reverts selections to last-saved — the escape the reference lacked. |

**Preserved from the reference (as instructed):** the save-mode decision, the review-changes grouping, the locked session-name row, session-notes change, `+ Incline Dumbbell Press`, `− Pec Deck`, and the Bench Press `Sets 4→5` / `Rest 90→120 s` modifications, and the bottom Save action.

**Continuity note:** these deltas are a *plan commit* — they change the stored template going forward and do not rewrite the logged Jun 9 session (which remains 4 sets @ 90 s). No earlier screen is contradicted. Clock 10:47 continues the now-line after Edit Session (10:46).
